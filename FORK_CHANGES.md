# Emojiful 5.2.4-fix.1 — изменения форка

Основа: Emojiful `1.21-5.2.4` (MIT). Протокол и формат рецептов не менялись: рецепт `emojiful:emoji_recipe`
(`category`, `name`, `url`) совместим с оригиналом, KubeJS-скрипты переписывать не нужно.

## Картинки
- **GIF собираются как в браузере**: учитываются смещения кадров, логический размер холста и методы очистки
  (disposal). Оптимизированные GIF больше не рвутся и не дёргаются.
- **Задержка 0–1 сотых секунды → 100 мс** (как в браузерах). Раньше такие кадры выбрасывались, а GIF из одного кадра
  с нулевой задержкой вечно показывал значок загрузки.
- **Битый кадр в середине GIF** больше не ломает весь эмодзи — показываются уже прочитанные кадры.
- **WebP**: статичный и анимированный, lossy и lossless, с прозрачностью. Lossless и канал прозрачности декодируются
  собственным декодером (RFC 9649), lossy-цвет — библиотекой TwelveMonkeys (вложена в jar).
- **Формат определяется по содержимому файла**, а не по расширению в ссылке.
- **Пропорции сохраняются**: картинка вписывается в квадрат с прозрачными полями, а не растягивается.
- **Качественное уменьшение** (поэтапная билинейная фильтрация + mip-уровни, трилинейная фильтрация при отрисовке);
  мелкий пиксель-арт увеличивается целым множителем без размытия.

## Загрузка и кэш
- Общий пул из 4 потоков вместо отдельного потока на каждый эмодзи.
- Таймауты соединения (10 с) и чтения (30 с), лимит 20 МБ, повторные попытки с нарастающей паузой (до 4).
- Кэш `emojiful/cache/v2/` по хэшу **ссылки**, запись атомарная (недокачанный файл не ломает эмодзи навсегда).
- Раз за запуск игры кэш проверяется на сервере по ETag / Last-Modified: **заменённая картинка обновится** у игроков.
- Имя текстуры — хэш ссылки: кириллица, регистр и спецсимволы в имени эмодзи больше не дают совпадений текстур.
- Все кадры эмодзи — в одной текстуре-атласе; при переподключении к серверу ничего не скачивается и не грузится заново.

## Производительность текста
- Поиск эмодзи в тексте — один проход по строке (`EmojiMatcher`): коды `:name:` находятся одним обращением к
  хэш-таблице. Раньше каждая строка прогонялась через регулярные выражения всех ~2300 эмодзи, а начиная с 5.2.3 —
  ещё и заново на каждом кадре. Результаты совпадают со старым поиском (0 расхождений на 20 000 случайных строк).
- Замер: 20 строк чата с эмодзи — было 44 мс CPU на кадр, стало ~0,01 мс; 40 меняющихся строк без эмодзи
  (F3, анимированный TAB, таймеры в скорборде) — было 45 мс, стало 0,025 мс.
- Результаты кэшируются по содержимому строки и по самому объекту строки (чат, таблички, text_display); кэши
  ограничены по размеру. Текст без эмодзи возвращается как есть.
- Перенос строк больше не плодит новые стили-метки на каждый вызов (утечка памяти в 5.2.3+).
- Ширина текста (TAB, скорборд, GUI) учитывает жирный шрифт и другие стили.
- Подготовка пикселей текстуры — в фоновом потоке; в потоке отрисовки только загрузка в видеокарту.

## Таблички, text_display, ники, TAB
- Эмодзи рисуются ванильными типами рендера текста с учётом режима: смещение глубины на табличках и text_display
  (без мерцания с доской), полупрозрачный проход «сквозь стены» у ников, обычный — в GUI.
- Светящиеся таблички: обводка букв сохраняется и при наличии эмодзи в строке.

## Встроенный набор, манифест, предзагрузка
- Встроенный набор (~2000 эмодзи) берётся из `custom_assets_url` (по умолчанию — репозиторий автора
  InnovativeOnlineIndustries/emojiful-assets; можно указать свою копию). Списки категорий кэшируются на диске и
  используются, если хост недоступен.
- `manifest_url` (по умолчанию пусто — выключено): `manifest.json` с SHA-1 каждой картинки. Формат:
  `{"base": "https://host/path/", "files": {"dir/name.gif": "<sha1>"}}`. Клиент
  загружает его один раз за запуск; картинка из кэша с совпадающим хэшем используется без запросов, изменённая —
  скачивается заново. Картинки вне манифеста проверяются по ETag, как раньше.
- `prefetch_server_emojis` (вкл.): после входа на сервер все его эмодзи скачиваются в дисковый кэш в фоне
  (отдельный пул из 3 потоков с низким приоритетом, не мешает эмодзи на экране). Декодирование — только при показе.
- Удалены тестовые рецепты автора `:comfy:` и `:kappa:` (ссылки на cdn.discordapp.com), вшитые в мод.

## Отрисовка и логика
- Убрана всплывающая подсказка при наведении на эмодзи в чате; эмодзи сохраняет собственные hover/click текста
  (например, подсказку плагина чата на нике).
- Окно выбора: прокрутка списка эмодзи больше не сбрасывает список категорий наверх — он сдвигается, только
  если текущая категория ушла за видимую область.
- Эмодзи затухают вместе с текстом чата.
- **Серверные эмодзи важнее встроенных** при совпадении кода (`:cat:`, `:thumbsup:` и т. п.); в лог пишется замена.
- Категории сервера сопоставляются без учёта регистра.
- Спецсимволы в именах (`. + ? [ $` …) экранируются полностью.
- Исправлен баг очистки категорий при перезагрузке рецептов (`getKey()` → `getValue()`).

## Версии
- Целевая: Minecraft 1.21.1 + NeoForge 21.1.200. Сборка идёт против 21.1.200.
- Проверено в игре: NeoForge 21.1.200 вместе с Sodium, Sodium Extra и Iris; ранее — NeoForge 21.0.84-beta (1.21).
- Требования в `neoforge.mods.toml` не менялись: Minecraft `[1.21,)`, NeoForge `[21.0.84-beta,)`.
- В dev-окружении ASM принудительно 9.8 (NeoGradle 7.0.145 иначе не запускает 21.1.x).

## Сборка
```
JAVA_HOME=<JDK 21> ./gradlew :NeoForge:build -x javadoc -x javadocJar
```
Готовый jar: `NeoForge/build/libs/Emojiful-Neoforge-1.21-5.2.4-fix.1-all.jar`.

## Локальная проверка
В `NeoForge/run/server` лежит тестовый сервер с датапаком `emojitest` (эмодзи с GitHub, таблички, text_display,
стойка с именем, префикс команды, сообщения в чат). Запуск:
```
./gradlew :NeoForge:runServer
./gradlew :NeoForge:runClient -PtestJoin=127.0.0.1
```
